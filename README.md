## ⭐ Flagship Project — CodeIntel-RAG

> **Agentic RAG platform for natural-language querying over codebases**

| Metric | Value |
|:---|:---|
| Hit@5 | **1.00** |
| MRR | **0.845** |
| Improvement vs semantic baseline | **+8.7%** |
| Languages supported | Python · Java · JavaScript · TypeScript · C++ |

**Architecture highlights:**
- 5-signal hybrid retrieval: BGE embeddings + FAISS · BM25Okapi · call-graph traversal · file-metadata · name-token matching
